The first set of scripts focuses on screen consolidation and enrichment. They iterate over several screener screens, extract unique company URLs with pagination, and map each raw URL slug to its official displayed company name. For every company, they fetch supplementary data including broad industry category, industry, market cap, stock P/E, and current price, storing results in JSON caches to avoid repeated requests. The consolidated output is a date-stamped Excel workbook containing a summary sheet, per-screen sheets, an all-companies sheet, and separate sheets grouped by broad industry and industry, along with a numeric data sheet meant for further analysis.

The second set of scripts handles document downloading, both for single companies and for batches. They parse public pages for quarterly reports, annual reports, concall transcripts/PPTs, credit ratings, and recent announcements, and use authenticated sessions (with hardcoded CSRF/session tokens) to also fetch important announcements, company profiles, related-party transactions, corporate actions, and trades data. The download engine handles PDFs, ZIP archives (which are extracted), and HTML pages (converted to PDF via a headless browser), with DNS checks, retry logic, and problematic-domain handling. Failed downloads are logged to a dead-links file, and each company's documents are saved into a dedicated folder under a downloads directory.

The third script carries out deep financial analysis. Using a headless browser, it expands all financial tables (quarterly results, profit & loss, balance sheet, cash flows, ratios, and shareholding pattern) on each company page, then extracts the metric rows and computes QoQ and YoY percentage/absolute changes. The results are written as per-company CSV files organized into date-stamped batch subfolders, with a master Excel tracker that lists companies and provides columns for classification, key reasons, risks, and confidence scores. JSON caches and a dated log file are used to track progress and avoid re-processing companies that have already been analyzed.
